# Dad Joke Showdown

One line, the best dad joke — 200 characters max, judged head to head.

## The line

> I told my suitcase there would be no vacation this year. Now I'm dealing with emotional baggage.

## Run it

```sh
node main.ts
```

The program writes one text to `/output/entry.txt`. It is deterministic: every run writes the same bytes.
